# ぷよぷよ（PUYO PUYO）— ゲーム追加

## 今回やること

レトロゲームセンターに落ち物パズル「ぷよぷよ」を追加する。
今回は**ゲーム本体の実装からメニュー統合まで**を一括で行う
（ヘビゲームでは実装とメニュー統合を2つの作業に分けたが、今回はまとめる）。

原作（1991年 コンパイル / 初代ぷよぷよ）のコアの再現ポイント：

- 2個1組の「組ぷよ」が上から落ちてくる。軸ぷよを中心に子ぷよが回転する。
- 同じ色が**縦横に4個以上つながる**と消える。
- 消えた上のぷよは落下し、それでまた4個つながれば**連鎖**して続けて消える。
- 連鎖が伸びるほど得点が跳ね上がる（連鎖ボーナス）。
- 盤面中央上部（おじゃま位置＝12列目3段目相当）が埋まるとゲームオーバー。

本作の他ゲーム（テトリス・DK81・アイスクライマー・スネーク）と統一された作りにする：
`BaseScene` 継承、`config.py` に `PUYO_` 接頭辞で定数、`synth_audio` の SE を再利用、
ゲームオーバーはテトリスと同じ**シーン内オーバーレイ**方式（`R` でリスタート／`ESC` でメニュー）。

## 画面・操作

- 解像度 800×600（既存共通）。盤面は 6 列 × 12 行・ぷよ 4 色（**原作準拠**）。
  1マス 40px → 240×480px。テトリスと同様に盤面を左寄せ、右側に NEXT・NEXT2・スコア・連鎖表示。
- 操作（**回転は Z / X の2キー**。本作テトリスの流儀と共通で、指の位置を覚え直さずに済む）：

  | キー | 動作 |
  |------|------|
  | ← → | 左右移動 |
  | ↓（押しっぱなし可） | 高速落下（ソフトドロップ） |
  | X | 右回転（時計回り・A ボタン相当） |
  | Z | 左回転（反時計回り・B ボタン相当） |
  | R | ゲームオーバー時にリスタート |
  | ESC | メニューへ戻る |

- ESC は `main.py` の `GameManager.handle_events` が全シーン共通で横取りするため、
  `PuyoPuyoScene` 側では扱わない（テトリス・スネークと同じ）。

- **操作説明は画面内に常時掲載する**。盤面右のサイドパネル下部に `CONTROLS` 見出しで
  上表の内容を並べる（テトリスの `_draw_side_panel` と同じ体裁・同じ位置に揃える）。
  遊ぶ前にキーを調べなくてよい状態にするのが目的なので、プレイ中ずっと出しっぱなしにする。

  ```
  CONTROLS
  <- -> : MOVE
  v (HOLD): DROP
  X : ROTATE R
  Z : ROTATE L
  R : RESTART
  ESC : MENU
  ```

## 受け入れ条件

- [x] 2個1組の組ぷよが盤面上部に出現し、一定間隔で1マスずつ落下する
- [x] ← → で左右に動かせる。壁・既存ぷよにぶつかる位置には動かせない
- [x] X / Z で軸ぷよを中心に子ぷよが 90 度ずつ回転する。壁際で回転できない場合は
      壁蹴り（軸ぷよを1マス押し戻す）で回転を成立させる
- [x] ↓ を押している間は高速落下し、押した瞬間にも1マス落ちて即応する
- [x] 着地後、**軸ぷよと子ぷよはそれぞれ独立して落下する**
      （片方だけ空中に残った場合、下まで落ちる＝原作の「ちぎり」）
- [x] 同色が縦横に 4 個以上つながると消える（斜めはつながらない）
- [x] 消えた後に上のぷよが落下し、再び 4 個以上つながれば連鎖が続く
- [x] 連鎖数に応じて得点が増える（連鎖ボーナス。1連鎖より2連鎖の方が大幅に高得点）
- [x] 連鎖中は「◯連鎖！」の表示が出て、連鎖が視覚的にわかる
- [x] 消去 → 落下 → 再判定の間はプレイヤー操作を受け付けない（アニメーション中の入力ロック）
- [x] NEXT に**次の組ぷよと、その次の組ぷよ（2手先）**が表示される
      （原作と同様、next / next2 の2つを常に先読みできる。next2 は少し小さめに描いて
      「次」「その次」の優先度が一目でわかるようにする）
- [x] ぷよが積み上がり、出現位置（3列目の最上段）が埋まった状態で新しい組ぷよを
      出せなくなるとゲームオーバーになる
- [x] ゲームオーバー時に盤面上へオーバーレイ表示され、`R` でリスタートできる
- [x] **操作説明が画面内（盤面右のサイドパネル下部）に常時表示される**。
      移動・ソフトドロップ・左右回転・リスタート・メニューの全キーが載っており、
      NEXT / NEXT2 / スコア / 連鎖表示と重ならず、画面下端（600px）に収まっている
- [x] メニューに「PUYO PUYO」カードが追加され、専用サムネイルが表示され、
      ENTER で実際にプレイできる
- [x] SE が鳴る（移動・回転・着地・消去・連鎖・ゲームオーバー）
- [x] ヘッドレス（画面描画なしで盤面ロジックを直接呼ぶ）デバッグスクリプトで、
      連結判定・消去・連鎖・ちぎり・得点計算が正しく動くことを確認する
- [x] 実際に `main.py` から起動し、メニュー → プレイ → ゲームオーバー → メニューの
      一連の流れを目視で確認する

## やらないこと（スコープ外）

- 対戦モード・CPU 対戦（**ユーザー確認済み：いったん不要**。1人用エンドレスで成立させる）
- おじゃまぷよ（対戦がないため発生しない）
- 全消しボーナス（対戦・おじゃま前提の要素のため今回は入れない）
- ステージ・レベル進行（テトリスのようなレベルアップによる落下速度上昇は入れるが、
  ストーリーモード・キャラクター演出は対象外）
- BGM（SE のみ。既存 `synth_audio` の方針を踏襲）
- スコアの永続保存（他ゲームと同方針で実行中のみ保持）
- 「4個以上同時消し」のボーナス（連結ボーナス・複色ボーナス）は簡易版に留める

| 変更 | `src/config.py` | `PUYO_` 接頭辞の定数を追記（盤面サイズ・落下速度・ぷよ色） |
| 変更 | `src/scenes/menu_thumbnails.py` | `_draw_puyo_puyo` を追加し `_DRAWERS` に登録 |
| 変更 | `src/scenes/menu_scene.py` | `GAMES` に `("PUYO PUYO", "puyo_puyo", "puyo_puyo")` を追加 |

> SE は既存 `synth_audio.py` の音を再利用し、新規追加は行わない：
> 移動＝`move`、回転＝`rotate`、着地＝`lock`、消去＝`line`、連鎖（2連鎖以上）＝`levelup`、
> ゲームオーバー＝`death`。
