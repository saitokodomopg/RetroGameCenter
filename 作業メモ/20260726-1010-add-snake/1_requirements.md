# ヘビゲーム（SNAKE）— ゲーム単体実装

## 今回やること

レトロゲームセンターに新しいゲーム「ヘビゲーム（Snake）」を追加する。
**今回はゲーム単体のコードのみ**が対象。メニューへの組み込み（カード追加・サムネイル）や
`main.py` へのシーン登録は別の担当者が行うため、今回のスコープには含めない。

原作（クラシック Snake）のコアの再現ポイント：

- グリッド上をヘビが移動し、一定間隔ごとに1マス進む。
- エサを食べると体が1マス伸び、スコアが加算される。
- エサを食べるたびに移動速度が少しずつ上がり、じわじわ難しくなる（上限あり）。
- 壁に当たる、または自分の体に頭がぶつかるとミス（ゲームオーバー）。
- クリア（ゴール）の概念はなく、スコアを伸ばし続けるエンドレスな生存型ゲーム。

本作の他ゲーム（DK81・テトリス・アイスクライマー）と統一された作りにする：
`BaseScene` 継承、`config.py` に `SNAKE_` 接頭辞で定数、`synth_audio` の SE、
ゲームオーバーは共通の `GameOverScene` を再利用（メッセージはゲームごとに差し替え）。

## 画面・操作

- 解像度 800×600（既存共通）。グリッドはマス目状（例：1マス20px → 40×30マス）。
- 操作：
  - ← → ↑ ↓ または W A S D : 進行方向を変更（真後ろへの反転は不可）
  - ESC : メニューへ戻る。`main.py` の `GameManager.handle_events` が全シーン共通で
    KEYDOWN+ESCAPE をグローバルに横取りしてメニューへ遷移させる既存の仕組みのため、
    `SnakeScene` 側で個別の実装は不要（`handle_input` で ESC を横取り・別用途に使わない）

## 受け入れ条件

- [x] ヘビが矢印キー／WASD で上下左右に方向転換できる（進行方向の真反対には曲がれない）
- [x] グリッド単位で移動し、一定間隔ごとに1マス進む
- [x] エサを食べると体が1マス伸び、スコアが加算され、体と重ならない空きマスに新しいエサが出現する
- [x] エサを食べるたびに移動速度が少しずつ上がる（上限を設けて無限に速くなりすぎない）
- [x] 壁（グリッド外）に頭が出るとミスになり `GameOverScene` に遷移する（`GameOverScene` は
      元々ゲーム名非依存の汎用実装のため、`score` kwarg のみ渡す形で無変更のまま利用）
- [x] 自分の体に頭がぶつかるとミスになり `GameOverScene` に遷移する
- [x] HUD にスコア・ハイスコア・速度段階（LV=食べたエサ数）を表示する
- [x] `SnakeScene.handle_input` は ESC キーを消費・別用途に使用しない（既存の `main.py` 側
      グローバル処理により、シーン登録後に ESC でメニューへ戻れることを妨げないようにする）
- [x] ヘッドレス（画面描画なしでシーンの update/状態を直接呼び出す）自動プレイのデバッグスクリプトで、
      移動・エサ取得・自己衝突・壁衝突・スコア加算・速度上昇が正しく動作することを確認する
      （`main.py` 経由での起動確認は今回のスコープ外）

## やらないこと（スコープ外）

- メニューへのカード追加・サムネイル画像の作成
- `main.py` へのシーン登録（`scene_manager` への統合）
- クリア（ゴール）演出・`ClearScene` との連携
- 壁を貫通するワープ挙動
- 障害物ブロックや複数ステージ
- BGM（効果音のみ、既存 `synth_audio` パターンを踏襲）
- スコアの永続保存（DK81・テトリス・アイスクライマーと同方針で、実行中のみ保持）
