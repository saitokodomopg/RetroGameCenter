# ピンボール（PINBALL）— ゲーム追加

## 今回やること

レトロゲームセンターに固定1テーブルの「ピンボール」を追加する。
ヘビ・ぷよぷよと同様、**ゲーム本体の実装からメニュー統合まで**を一括で行う。

原作系ピンボールのコアの再現ポイント（1テーブル構成のシンプル版）：

- プランジャー（発射装置）でボールを打ち出す。
- 左右のフリッパーでボールを跳ね返し、盤面上部へ打ち上げる。
- ポップバンパー・スリングショットに当たると跳ね返り、得点が入る。
- ボールが下端の溝（アウトレーン／ドレイン）に落ちるとミス。
- ボールは3個（3ボール制）。全部落とすとゲームオーバー。

本作の他ゲーム（テトリス・スネーク・ぷよぷよ）と統一された作りにする：
`BaseScene` 継承、`config.py` に `PINBALL_` 接頭辞で定数、`synth_audio` の SE を再利用、
ゲームオーバーは `GameOverScene`（他ゲームと共通）に遷移してスコアを表示する。

物理は既存ゲーム群と同じく **pygame の速度・当たり判定ベースの自前実装**とし、
新規の物理演算ライブラリ（pymunk 等）は導入しない（アーキテクチャ変更なし）。

## 画面・操作

- 解像度 800×600（既存共通）。盤面は縦長のピンボール台を画面中央に配置し、
  右側に SCORE・BALL（残機）を表示するサイドパネルを設ける。
- 操作：

  | キー | 動作 |
  |------|------|
  | ↓（押し込み→離す） | プランジャーを引き込み、離した強さでボールを発射 |
  | ← | 左フリッパーを跳ね上げる |
  | → | 右フリッパーを跳ね上げる |
  | ESC | メニューへ戻る |

- ESC は `main.py` の `GameManager.handle_events` が全シーン共通で横取りするため、
  `PinballScene` 側では扱わない（他ゲームと同じ）。
- ゲームオーバー後のリスタートは、共通 `GameOverScene` の挙動（**ENTER でメニューへ戻り、
  メニューから選び直す**）に従う。スネーク・アイスクライマー・space invaders 等の多数派と
  同じ方式で、テトリス・ぷよぷよのようなシーン内 `R` リスタートは持たない
  （`GameOverScene` 自体が ENTER 専用のため）。
- **操作説明は画面内に常時掲載する**（サイドパネル下部に `CONTROLS` 見出し）。

  ```
  CONTROLS
  DOWN (HOLD/RELEASE): LAUNCH
  <- : LEFT FLIPPER
  -> : RIGHT FLIPPER
  ESC : MENU
  ```

## 受け入れ条件

- [x] ボールは初期状態でプランジャーレーンに静止しており、↓キーを押し込んでいる時間で
      発射の強さが決まり、離すと盤面上部へ打ち出される
- [x] 左右のフリッパーは対応するキーを押している間だけ跳ね上がり、離すと重力で下がる
- [x] ボールがフリッパーに当たると、フリッパーの角速度に応じて跳ね返る方向・速度が変わる
- [x] ポップバンパーに当たるとボールが反発し、得点が加算される（当たるたびに加算）
- [x] スリングショットに当たるとボールが反発し、得点が加算される
- [x] 盤面外周の壁でボールが自然に跳ね返る（壁にめり込まない）
- [x] ボールが下端の溝（両フリッパーの間）に落ちるとミスになり、残機が1減る
- [x] ミス後、残機が残っていれば自動でボールがプランジャーレーンにリセットされ、再発射できる
- [x] 残機（3個）を使い切るとゲームオーバーとなり、`GameOverScene` に遷移してスコアを表示する
- [x] `GameOverScene` から `ENTER` でメニューへ戻れる（他ゲームと同じ挙動。共通コンポーネントの
      既存動作をそのまま利用するため実装は不要）
- [x] **操作説明が画面内（サイドパネル下部）に常時表示される**
- [x] SE が鳴る（発射・フリッパー作動・バンパー命中・スリングショット命中・ミス）
- [x] メニューに「PINBALL」カードが有効化され（既存サムネイルを流用）、ENTER で実際にプレイできる
- [x] `main.py` から実起動し、例外なくウィンドウが起動することを確認
      （※後述「動作確認について」の理由により、キー操作を伴う目視での一連の流れ確認は
      未実施。物理・状態遷移の妥当性はヘッドレスシミュレーションで検証済み）

## やらないこと（スコープ外）

- 複数テーブル・テーブル選択（1テーブル固定）
- マルチボール（同時に複数個のボールが出る演出）
- ティルト（台を揺らす操作・ペナルティ）
- ランプ・キックバック・ボーナスマルチプライヤーなどの高度なギミック
- ハイスコアの永続保存（他ゲームと同方針で実行中のみ保持）
- BGM（SE のみ。既存 `synth_audio` の方針を踏襲）

## 動作確認について（実施内容と制限）

- ヘッドレスの物理シミュレーション（`pygame.init()` 済み・`SDL_VIDEODRIVER=dummy`）で
  複数シードにわたり60〜90秒分プレイをシミュレートし、以下を確認した：
  - プランジャー発射がレーン開口部（盤面上部の合流点）まで届く初速になっているか
    （当初 `PINBALL_LAUNCH_MAX_SPEED` が重力に対して弱く、レーンから出られないバグを発見・修正）
  - 高速時に壁をすり抜けない（サブステップ衝突解決を追加して修正。修正前は盤面外に
    ボールが飛び出すバグがあった）
  - 静止時のフリッパー先端の当たり判定円が左右で重なり、ドレインの隙間を塞いで
    ボールが永久に詰まるバグを発見・修正（`PINBALL_FLIPPER_PIVOT_OFFSET` を拡大）
  - 打ち上げが弱くレーンへ戻った際に操作不能になるバグを発見・修正
    （`Table.is_settled_in_lane` で検知し `ready` 状態へ戻す）
  - 上記修正後、複数シードで壁のすり抜け・詰まりが再発しないことを確認
- `python src/main.py` を実起動し、ウィンドウ（タイトル "Retro Game Center"）が例外なく
  開くことを確認した。
- **キー操作を伴う目視確認は未実施**：スクリーンショット取得のためにウィンドウをフォアグラウンドへ
  切り替えようとしたところ、別の全画面アプリ（ユーザーが実行中の Roblox）にフォーカスが
  奪われてしまい、画面キャプチャが本アプリではなくユーザーの Roblox 画面（チャットログ等の
  個人情報を含む）を映してしまった。プライバシーに配慮しその画像は直ちに削除し、
  それ以降のスクリーンショット取得は中止した。そのため、メニュー→プレイ→ミス連続→
  ゲームオーバー→メニューの一連の流れの**目視確認はできていない**。
  ユーザー側で実機確認をお願いしたい。
