# ワギャンランド（WAGYAN LAND）— 1 ステージ実装

## 今回やること

レトロゲームセンターに 5 本目のゲーム「ワギャンランド」を追加する。
**1 ステージ＋ボス戦のみ**だが、原作コアの手触り（音波でしびれさせて足場にする
アクション ＋ ボスとの知恵比べ）をしっかり再現し、**完成度**にこだわる。

原作コアの再現ポイント：

- 主人公 **ワギャン**（恐竜とロボットを掛け合わせたような緑色の生物）を
  左右移動・ジャンプで操作する。
- ステージは基本 **右方向スクロール**（今回は右スクロールの基本形 1 本のみ実装）。
- 攻撃は口から発する **「ワッ」「ギャー」等の音波**。敵を**倒すことはできない**が、
  一定時間**しびれさせる**ことができる。しびれている敵の上には**乗ることができ、
  足場として利用できる**（このギミックをステージ攻略の中心に据える）。
- ステージ内に配置された **「ワギャナイザー」**（拡声器アイテム）を取るたびに
  音波が強化され、**ワッ → ギャ → ガー → ギャー** の4段階でレベルアップする。
  レベルが上がるほど音波の届く範囲が広がり、しびれ時間も長くなる。
- ステージ終端で **ボス** と対戦する。ボス戦は原作同様「アクションで倒す」のではなく
  **知恵比べのミニゲーム**で決着をつける。今回は以下の2種を実装し、
  **ボス戦に入るたびランダムでどちらか一方が選ばれる**：
  - **神経衰弱**：カードをめくって同じ絵柄のペアを揃える。既定ペア数を
    先に揃えた方（プレイヤー or ボス）が勝ち。
  - **しりとり**：表示された単語としりとりが繋がる単語を、プレイヤーと
    ボスが交互に出し合う。次の単語が出せなくなった方が負け。
    ※キーボードでの自由入力は行わず、**候補の中から選択する方式**にする
    （日本語自由入力の判定実装を避け、スコープを適正化するため）。
  - ミニゲームに**勝てばステージクリア**、**負ければミス扱い**（残機を1つ消費し、
    ステージ側の再挑戦 or 残機切れで GameOver）。

原作を尊重しつつ、本作の他ゲーム（DK・DK81・テトリス・アイスクライマー）と
統一された作りにする：`BaseScene` 継承、`config.py` に `WAGYAN_` 接頭辞で定数、
`synth_audio` の SE、クリア/ゲームオーバーは既存の共通シーン（kwargs 方式）を
そのまま再利用する。

## 画面・操作

- 解像度 800×600（既存共通）。横スクロールでステージの一部を表示、
  ワギャンが右へ進むと画面が追従する。
- 操作：
  - ← → : 左右移動
  - ↑ または Z : ジャンプ
  - スペース : 音波攻撃（レベルに応じた「ワッ」〜「ギャー」を発する）
  - ボス戦（ミニゲーム中）：矢印キーで選択、スペース/エンターで決定
  - ESC : メニューへ戻る（既存共通）

## ステージ構成（1 面＋ボス）

- 右スクロールの地上ステージ。足場・隙間・歩行する敵を配置。
- 敵は音波でしびれさせると一定時間その場で気絶し、上に乗って足場にできる
  （隙間を越えるための踏み台として機能させる）。
- ステージ中に **ワギャナイザー** を複数個配置し、取得順に音波レベルが上がる
  （ステージ内では上限レベルまで到達できる個数を配置）。
- ステージ終端に到達すると **ボス戦エリア** へ移行し、神経衰弱／しりとりの
  いずれかがランダムに開始する。

## 受け入れ条件

- [x] ワギャンが左右移動・ジャンプでき、音波攻撃（スペース）で敵をしびれさせられる
- [x] しびれた敵の上に乗って足場として利用できる（乗っている間は敵が復帰しない）
- [x] ワギャナイザーを取得すると音波レベルが上がり（ワッ→ギャ→ガー→ギャー）、
      範囲としびれ時間が段階的に強化される
- [x] ステージ終端に到達するとボス戦へ移行する
- [x] ボス戦は毎回ランダムで「神経衰弱」または「しりとり」のどちらかが選ばれる
- [x] 神経衰弱：カードをめくって一致判定ができ、規定ペア数を先取した側が勝つ
- [x] しりとり：候補選択式で単語を出し合い、しりとりが続けられなくなった側が負ける
- [x] ボス戦に勝つと Clear シーンへ、負ける（残機切れ）と GameOver シーンへ遷移する
- [x] 音波攻撃・しびれ・ワギャナイザー取得・ボス戦の選択/勝敗に合成 SE が鳴る
- [x] HUD（スコア・残機・音波レベル）表示
- [x] `main.py` にシーン登録され、`python src/main.py` で（メニュー経由以外の）
      直接遷移確認ができる状態になっている
- [x] `python src/main.py` で起動し、ヘッドレス自動プレイでステージ〜ボス戦〜
      クリアまで通しで確認できる

## やらないこと（スコープ外）

- メニュー画面（`menu_scene.py` / `menu_thumbnails.py`）へのカード追加 —
  担当者が別途対応するため、本作業では触れない
- ステージ 2 以降、左スクロール・縦スクロールステージ
- しりとりの自由テキスト入力・本格的な日本語辞書判定（候補選択式に簡略化）
- ストーリー演出（Dr. デビルとのイントロ・エンディングカットシーン等）
- スコアの永続保存（実行中のみ HIGH を保持、DK81・アイスクライマーと同方針）
- タイルマップ（Tiled）化 — 本ステージは stage モジュールにハードコードで定義
